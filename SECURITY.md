# Security Policy

## Supported Versions

The following versions of `behave-modern-console-report` are currently being
supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

1. **Do not** open a public GitHub issue.
2. Report it privately through [GitHub Security Advisories](https://github.com/MathiasPaulenko/behave-modern-console-report/security/advisories/new)
   with a description of the vulnerability, steps to reproduce, and any
   relevant proof of concept.
3. You will receive an acknowledgment within 48 hours.
4. A fix will be developed and released as soon as possible, and you will be
   credited (unless you prefer to remain anonymous).

## Disclosure Policy

- Vulnerabilities will be disclosed publicly only after a fix has been released.
- We follow coordinated disclosure and will work with you to determine an
  appropriate timeline.
